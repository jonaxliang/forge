# Forge Cat Mascot Actions

Generated mascot action assets based on the current Forge cat brand image.

## Files

- `forge-cat-mascot-info.png` - neutral informational reminder.
- `forge-cat-mascot-success.png` - completed or approved state.
- `forge-cat-mascot-warning.png` - caution, validation warning, or pending attention.
- `forge-cat-mascot-blocked.png` - blocked, failed, or needs human action.
- `forge-cat-mascot-thinking.png` - loading, planning, analysis, or in-progress work.
- `forge-cat-mascot-guide.png` - empty state, onboarding, or directional prompt.
- `forge-cat-mascot-actions-preview.png` - contact-sheet preview on a light background.

## Usage Notes

- Use the transparent PNG action assets in reminder panels, empty states, approval prompts, and workflow status surfaces.
- Prefer small supporting placement rather than hero-scale use; these are UI accents for the Control Room experience.
- Pair the assets with concise operational copy. Avoid using them as decorative filler.
